HOODZ

An open-source Luau UI library. Red and black, built from floating panels instead of one window, with music and settings wired in from the start.

v1.3open sourcemobile + pcreload-safe

Start hereone line, then your first tab

Put three files in your repo root, on the main branch: HoodzLib.lua, the logo IMG_3411.jpeg, and the song substance.mp3. Nothing else needs configuring — both the logo and the song download on first run and are cached in the executor's workspace.

  1. [1]
    Load the library. One loadstring call returns the library table.
  2. [2]
    Build the window. Hoodz.new({ Title = "Hoodz" }) starts the loading sequence and returns the UI.
  3. [3]
    Add a category and a tab. Categories are the circles on the rail; tabs live inside a category.
  4. [4]
    Add components. Toggles, sliders, buttons, labels, and sections — each tied to a callback.
quick-start.lua
local Hoodz = loadstring(game:HttpGet("https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/HoodzLib.lua"))()
local UI = Hoodz.new({ Title = "Hoodz" })

local tab = UI:CreateCategory("Player"):CreateTab("Movement")
tab:CreateToggle({ Name = "Speed boost", Callback = function(on) print(on) end })
tab:CreateSlider({ Name = "Walk speed", Min = 16, Max = 100, Default = 16, Callback = function(v) print(v) end })
Tap the logo in the top-left corner, or press RightShift, to show or hide the UI at any time — including while it's still mid-way through loading.

How it's builtfive panels, one shared background

Hoodz isn't one window with a sidebar bolted on. It's separate rounded panels — islands — that share one pixel-gradient background and move together. Dragging the header drags all of them.

UI methods

callreturnswhat it does
UI:CreateCategory(name)CategoryAdds a circle to the rail.
UI:CreateTab(name, categoryName?)TabShortcut — finds or creates the category, then adds the tab.
UI:SetVisible(bool)—Shows or hides the UI with a fade.
UI:Toggle()—Flips visibility.
UI:IsLoaded()booleanTrue once the loading sequence has finished.
UI:WaitUntilLoaded(timeout?)booleanYields until loading finishes. Default timeout: 30s.
UI:SetMusic(bool)—Turns the song on or off and saves the choice.
UI:SetVolume(0–100)—Sets and saves the normal volume.
UI:SetCrossfade(1–10)—Sets and saves the loop's overlap length.
UI:Destroy()—Removes the UI, the music, and every connection.

The current values live in UI.Settings — a plain table with Music, Volume, and Crossfade.

Componentseverything you can put on a tab

Section & label

A section is a small heading with no interaction. A label returns an object so you can update its text later.

components.lua
tab:CreateSection("Movement")
local status = tab:CreateLabel("Status: idle")
status:Set("Status: running")

Toggle

Toggles pair up two per row. A lone toggle stays full width until its partner is created.

toggle.lua
local fly = tab:CreateToggle({
    Name = "Fly",
    Default = false,
    Callback = function(on) print("fly:", on) end,
})
fly:Set(true)          -- flips it and fires the callback
fly:Set(true, true)    -- flips it silently
fly:Get()                -- current state

Its callback fires once on creation only if Default = true. Pass NoInit = true to skip that first call entirely.

Slider

Sliders are full width. Dragging one never scrolls the page or drags a neighbor — each drag has a single owner.

slider.lua
local speed = tab:CreateSlider({
    Name = "Walk speed",
    Min = 16, Max = 100, Default = 16, Increment = 1,
    Callback = function(v) print("speed:", v) end,
})
speed:Set(50)
speed:Get()

Its callback always fires once on creation, with the default value, unless NoInit = true is set.

Button

Buttons pair up two per row, the same as toggles.

button.lua
tab:CreateButton({
    Name = "Reset",
    Callback = function() speed:Set(16) end,
})

Music & settingsbuilt in, nothing to wire up

substance.mp3 follows a fixed script with no setup required:

  1. [1]
    Loading. It plays loud and sounds underwater — muffled highs, a slow wobble, a watery echo.
  2. [2]
    Settling. Once loading ends, the effect and the loudness fade out over about 2.5 seconds.
  3. [3]
    Looping. It plays low and clean. Near the end of the track a second copy fades in from the start while the first fades out — the loop never hard-restarts.

The last circle on the rail, Hoodz, is the built-in settings page — a music on/off switch, a volume slider, and a loop-crossfade slider, all saved to Hoodz_Settings.json in the workspace and restored on the next run. The dock also has a quick on/off switch.

Reloadingrun it twice, get one window

Loading HoodzLib.lua a second time — or calling Hoodz.new twice from the same loaded copy — destroys the previous UI, its music, and every connection before building the new one. Edit your script and run it again without leaving the game.

reload.lua
-- run this twice in a row: you still end up with exactly one window
local Hoodz = loadstring(game:HttpGet("https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/HoodzLib.lua"))()
local UI = Hoodz.new({ Title = "Hoodz" })

Testing & shippingbefore you hand it to anyone else

The repo's test.lua builds a demo UI covering every component, then checks itself — toggles, slider clamping and rounding, settings, show/hide — and prints a PASS/FAIL report straight into a Tests tab.

run-tests.lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/test.lua"))()

Handing this to other people? Keep HoodzLib.lua readable in the repo for development, and obfuscate a separate release copy before pointing a public loadstring link at it — the source as written here is plain, unobfuscated Lua.

Logcommon issues

The logo doesn't show
Check that IMG_3411.jpeg sits in the repo root, or pass your own with ImageUrl. Your executor also needs getcustomasset, writefile, and isfile. Without a logo, a plain "H" button is used instead — the UI still works.
There's no sound
Confirm substance.mp3 is in the repo root, that Background music is on in the Hoodz settings tab, and that the volume slider is above 0. The first run has to download the file, which can add a few seconds to the loading screen.
The UI is the wrong size
Every panel scales to the screen automatically. If it still looks off on a particular device, note the device and screen size and the scale limits in the library can be adjusted.
I want different colors
Every color lives in the Theme table near the top of HoodzLib.lua — exposed afterward as Hoodz.Theme. Change it there and every panel follows.
