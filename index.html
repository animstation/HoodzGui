How to use
Hoodz

Ten short parts. Each one adds one piece of code. Follow them in order and you end up with a complete, working script — shown in full at the end.

v1.310 parts1 script
Part One — The module

Loading it

Everything starts with one line. It downloads the module and hands back a table — call it Hoodz. Nothing is built yet; this just gets the tool into your hands.

step_01.lua
local Hoodz = loadstring(game:HttpGet("https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/HoodzLib.lua"))()

one line, no window yet

Part Two — The window

Building it

Hoodz.new is where the window actually appears. It starts the loading sequence, downloads the logo in the background, and hands back the UI you'll build everything else on top of.

step_02.lua
local UI = Hoodz.new({ Title = "Hoodz" })

a window exists, empty

Tap the logo top-left, or press RightShift, any time — even mid-load — to show or hide it.
Part Three — Categories & tabs

Giving it structure

A category is a circle on the rail. A tab lives inside a category. This is the skeleton everything else hangs on.

step_03.lua
local tab = UI:CreateCategory("Player"):CreateTab("Movement")

one circle, one tab, still empty

Part Four — The first switch

Adding a toggle

Toggles pair up two per row on their own — add a second one later and they'll sit side by side. Each one takes a name, a starting state, and a callback that fires on every flip.

step_04.lua
tab:CreateToggle({
    Name = "Speed boost",
    Default = false,
    Callback = function(on) print("speed boost:", on) end,
})

your first interactive control

Part Five — A number you can drag

Adding a slider

Sliders are full width. Each drag has a single owner, so grabbing one never scrolls the page or drags a neighbor — it fires once immediately with its default value, then again every time it moves.

step_05.lua
local speed = tab:CreateSlider({
    Name = "Walk speed", Min = 16, Max = 100, Default = 16, Increment = 1,
    Callback = function(v) print("walk speed:", v) end,
})

a value, live

Part Six — Doing something on command

Adding a button

No state, no default — just a name and a callback. Here it uses the slider from the part before to reset itself, which is the first time two pieces of this script talk to each other.

step_06.lua
tab:CreateButton({
    Name = "Reset speed",
    Callback = function() speed:Set(16) end,
})

a button, wired to the slider above it

Part Seven — Keeping it readable

Sections & labels

A section is a small heading, nothing more. A label is text you can update later — useful for showing status back to whoever's using the panel.

step_07.lua
tab:CreateSection("Movement")
local status = tab:CreateLabel("Status: idle")
status:Set("Status: running")

the tab, organized

Part Eight — What came for free

The music, already running

Nothing above touched sound, yet the window already has it: loud and underwater while it loaded, now settled into a low loop that fades into itself at the seam instead of restarting hard. It downloaded and cached the same way the logo did — automatically.

The last circle on the rail, Hoodz, holds the built-in settings — music on/off, a volume slider, a loop-crossfade slider. All three are saved and come back exactly as you left them.

None of this needed a line of your code. It's part of what Hoodz.new already built.
Part Nine — A different look

Themes

Same settings page has a second tab, Themes: four buttons — Hoodz, Black & Grey, Blue, White — each one recoloring every outline, highlight, toggle, and slider live, no rebuild. Whichever one is picked is remembered for that Roblox username and restored automatically next time.

Below the four buttons sits a plain text box. It does nothing for almost anyone who types in it. For the one person who knows what to type, it unlocks a fifth theme — flat, grey, deliberately static — that never appears as a button and was never meant to.

step_09.lua
local settings = UI:CreateCategory("Hoodz") -- already there - you don't build this one
UI:SetTheme("Blue")        -- or do it from code instead of the button

one script, five possible looks

Part Ten — Starting over

Reloading

Run the same script twice. The module notices, tears down the first window and its music completely, and builds the second one clean. Edit your script, run it again, never leave the game.

step_10.lua
-- run this twice in a row: you still end up with exactly one window
local Hoodz = loadstring(game:HttpGet("https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/HoodzLib.lua"))()
local UI = Hoodz.new({ Title = "Hoodz" })
The Full Picture

Every part, in order

This is parts one through seven, combined — nothing added. Paste it as one script and it runs.

combined.lua

Parts Eight through Ten need nothing pasted in — the music, the themes, and reloading are already part of what Hoodz.new builds.

combined.lua
local Hoodz = loadstring(game:HttpGet("https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/HoodzLib.lua"))()
local UI = Hoodz.new({ Title = "Hoodz" })

local tab = UI:CreateCategory("Player"):CreateTab("Movement")
tab:CreateSection("Movement")
local status = tab:CreateLabel("Status: idle")

tab:CreateToggle({
    Name = "Speed boost",
    Default = false,
    Callback = function(on) status:Set("Status: " .. (on and "running" or "idle")) end,
})

local speed = tab:CreateSlider({
    Name = "Walk speed", Min = 16, Max = 100, Default = 16, Increment = 1,
    Callback = function(v) print("walk speed:", v) end,
})

tab:CreateButton({
    Name = "Reset speed",
    Callback = function() speed:Set(16) end,
})

Appendix — Log

Common issues

The logo doesn't show
It downloads in the background on first load. If it still doesn't appear, a plain "H" swatch is used instead, colored to match the current theme — the UI still works.
No music
Check Background music is on in the Hoodz settings tab and the volume slider is above 0. The first run has to download the track, which can add a few seconds to loading.
A theme didn't apply everywhere
The background, outlines, highlights, toggles, and sliders all recolor live. The base dark panels and body text stay the same across every theme by design — themes change the accent and the background, not the whole UI into a literal light mode.
The hidden theme
It's unlocked by typing a specific code into the box under Themes → Code. What that code is isn't published here — ask whoever set it up for you.
The UI is the wrong size
Every panel scales to the screen automatically. If it still looks off on a specific device, note the device and screen size.
