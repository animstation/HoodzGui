Hoodz

An open-source Luau UI library with a pixel-gradient red and black background, floating panels instead of a boring window, built-in music with an underwater loading intro, and a one-line setup.

v1.3 Open source Mobile + PC Draggable Auto-reload
Luau
local Hoodz = loadstring(game:HttpGet("https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/HoodzLib.lua"))()
local UI = Hoodz.new({ Title = "Hoodz" })

local tab = UI:CreateCategory("Player"):CreateTab("Movement")
tab:CreateToggle({ Name = "Speed boost", Callback = function(on) print(on) end })
tab:CreateSlider({ Name = "Walk speed", Min = 16, Max = 100, Default = 16, Callback = function(v) print(v) end })

Quick start

  1. Put the files in your repo. HoodzLib.lua, IMG_3411.jpeg (the logo) and substance.mp3 (the song) go in the repo root on the main branch. Nothing else is needed.
  2. Load the library with the loadstring line above. The logo and the song download automatically the first time and are cached in your executor’s workspace folder.
  3. Create the UI with Hoodz.new({ Title = "Hoodz" }), then add categories, tabs and components.
  4. Show or hide it by tapping the logo in the top-left corner, or press RightShift.
You never configure the logo or the music by hand. If a download fails, the logo button shows a red “H” and the song stays silent; everything else still works.

Pixel-gradient background

One continuous red and black gradient made of pixel blocks flows toward the top-left behind every panel.

Floating panels

Header, category rail, tab list, tile grid and a dock. They move together and assemble one by one when loading finishes.

Built-in audio

Loud, underwater-sounding song while loading, then a low clean loop that crossfades with itself.

Reload-safe

Run the script twice and the old UI and music are replaced by the new code. No duplicates.

All devices

Scales to phones, tablets and PC. Touch sliders never scroll the page or drag each other.

Saved settings

Music on/off, volume and crossfade length are remembered between runs.

The layout

Hoodz does not use a single window with a sidebar. It uses separate rounded “islands” that share one background.

API reference

Hoodz.new(config)

Creates the UI and starts the loading screen. Every option is optional.

OptionDefaultWhat it does
Title"Hoodz"Name shown in the header and on the loading screen.
Subtitle"v1.3"Text of the small chip next to the title.
LoadingTime2.5Minimum seconds for the loading bar. First run may take longer while files download.
ToggleKeyEnum.KeyCode.RightShiftKey that shows or hides the UI.
MusictrueDefault for the music switch. A saved setting overrides it.
MusicVolume30Default normal volume, 0 to 100.
CrossfadeTime4Seconds of overlap when the song loops, 1 to 10.
Image, ImageUrllogo in the repoLocal file name and download link of the logo. Only change these to use a different logo.
MusicFile, MusicUrlsong in the repoLocal file name and download link of the song.
Name"Hoodz"Name of the ScreenGui. Keep the default so reloading can clean up leftovers.

UI methods

MethodReturnsWhat it does
UI:CreateCategory(name)CategoryAdds a circle to the rail. The first letter of the name is shown in the circle.
UI:CreateTab(name, categoryName?)TabShortcut: finds or creates the category, then adds the tab.
UI:SetVisible(bool)–Shows or hides the UI with a fade.
UI:Toggle()–Flips visibility.
UI:IsLoaded()booleanTrue once the loading screen has finished.
UI:WaitUntilLoaded(timeout?)booleanYields until loading finishes (default timeout 30 seconds).
UI:SetMusic(bool)–Turns the music on or off and saves the choice.
UI:SetVolume(0–100)–Sets the normal volume and saves it.
UI:SetCrossfade(1–10)–Sets the loop crossfade length in seconds and saves it.
UI:Destroy()–Removes the UI, the music and every connection.

Read the current settings from UI.Settings: Music (boolean), Volume (0–100) and Crossfade (seconds).

Category and Tab

Luau
local category = UI:CreateCategory("Player")   -- a circle on the rail
local tab = category:CreateTab("Movement")        -- a page in the tab list

Components (called on a tab)

ComponentOptionsReturned object
tab:CreateSection(text)text–
tab:CreateLabel(text)text:Set(text)
tab:CreateButton(opts)Name, Callback()–
tab:CreateToggle(opts)Name, Default, Callback(on):Set(bool, silent?), :Get()
tab:CreateSlider(opts)Name, Min, Max, Default, Increment, Callback(value):Set(value), :Get()
Tiles pair up. Two toggles in a row sit side by side; so do two buttons. A lone tile stays full width until its partner is created. A slider, label or section always starts a new row.
Callbacks on creation. A slider calls its callback once with its default value. A toggle calls its callback once only when Default = true. :Set(value, true) on a toggle changes it without calling the callback.

Full example

Luau
local Hoodz = loadstring(game:HttpGet("https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/HoodzLib.lua"))()
local UI = Hoodz.new({ Title = "Hoodz" })

local player = UI:CreateCategory("Player")

local movement = player:CreateTab("Movement")
movement:CreateSection("Speed")
local speed = movement:CreateToggle({
    Name = "Speed boost",
    Callback = function(on)
        print("speed boost", on)
    end,
})
movement:CreateToggle({ Name = "Infinite jump" })      -- pairs with the toggle above
movement:CreateSlider({
    Name = "Walk speed", Min = 16, Max = 100, Default = 16, Increment = 1,
    Callback = function(v) print("walk speed", v) end,
})
movement:CreateButton({ Name = "Reset", Callback = function() speed:Set(false) end })

UI:WaitUntilLoaded()
print("Hoodz is ready")

Music and settings

The song substance.mp3 is built in and follows a fixed script:

  1. Loading: it plays loud and sounds underwater (muffled highs, a slow wobble and a watery echo).
  2. Transition: when loading ends, the underwater effect and the loudness fade away over about 2.5 seconds.
  3. Loop: it plays low and clean. Near the end of the song a second copy fades in from the start while the first fades out, so the loop has no hard restart.

The last category on the rail, Hoodz, is the built-in settings page:

SettingRangeNotes
Background musicon / offWhen off, nothing is downloaded or played. The dock also has a quick switch.
Music volume0 – 100Normal volume after loading (default 30).
Loop crossfade1 – 10 secondsHow long the end and the start of the song overlap.

Settings are saved as Hoodz_Settings.json in the executor’s workspace folder, so they survive re-running the script.

Reloading

Running the script again is safe. When the library file is loaded a second time, the previous UI, its music and all of its connections are destroyed first, and the new code takes over. You can edit your script, run it again, and see the result without leaving the game.

Luau
-- run this twice: you still end up with exactly one Hoodz window
local Hoodz = loadstring(game:HttpGet("https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/HoodzLib.lua"))()
local UI = Hoodz.new({ Title = "Hoodz" })

Calling Hoodz.new twice from the same loaded library also replaces the first UI.

Run the test

The test script builds a demo UI that uses every component, then checks itself: toggles, slider clamping and rounding, the built-in settings, and show and hide. The results appear in Tests → Self-test and in the console. The UI loads once. To also test reloading, set RELOAD_TEST = true at the top of the script: it then loads the library a second time on purpose, so the loading screen and the music play twice.

Luau
loadstring(game:HttpGet("https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/test.lua"))()

Things to check by hand while it runs:

  • The loading screen covers the whole screen, including the sides, and the song starts loud and underwater.
  • After loading, the panels rise in one after another and the song settles into a low loop.
  • In Stress Test → Scrolling, hold one slider and drag up and down: only that slider moves.
  • Tap the logo to hide and show the UI. Drag the header to move all panels.
Show the full test script
test.lua
--[[
	Hoodz test script (v1.3)

	1. Loads the library from GitHub and builds a demo UI that exercises every component
	   (tile pairing, sliders, categories, scrolling).
	2. Runs a self-test (components, settings, show/hide) and shows every PASS / FAIL in
	   Tests > Self-test (also in the console).
	3. OPTIONAL: set RELOAD_TEST = true to also load the library a second time and prove that
	   reloading replaces the old UI. That makes the loading screen + music play twice,
	   so it is OFF by default.

	Sliders: grab one in "Stress Test > Scrolling" and drag up/down -
	only the slider you grabbed should move.
]]

local URL = "https://raw.githubusercontent.com/animstation/HoodzGui/refs/heads/main/HoodzLib.lua"

local RELOAD_TEST = false -- true = also load the library a 2nd time (UI loads twice on purpose)

local function loadLib()
	return loadstring(game:HttpGet(URL))()
end

local ok, Hoodz = pcall(loadLib)
if not ok or type(Hoodz) ~= "table" then
	warn("[Hoodz test] failed to load the library:", Hoodz)
	return
end

local results = {}
local function check(name, cond)
	table.insert(results, { name = name, ok = cond and true or false })
	print("[Hoodz test] " .. (cond and "PASS" or "FAIL") .. "  " .. name)
end

----------------------------------------------------------------------
-- Demo UI (nothing else is needed: logo + music are built in)
----------------------------------------------------------------------
local function build(lib, summary)
	local UI = lib.new({
		Title = "Hoodz",
		LoadingTime = 2,
		ToggleKey = Enum.KeyCode.RightShift,
	})
	local c = {}

	-- Category 1: Components
	local components = UI:CreateCategory("Components")

	local togglesTab = components:CreateTab("Toggles")
	local status = togglesTab:CreateLabel("Status: waiting...")
	togglesTab:CreateSection("Tiles pair up two per row")
	c.toggleA = togglesTab:CreateToggle({
		Name = "Toggle A",
		Default = false,
		Callback = function(on)
			status:Set("Toggle A = " .. tostring(on))
		end,
	})
	togglesTab:CreateToggle({
		Name = "Toggle B",
		Default = true,
		Callback = function(on)
			status:Set("Toggle B = " .. tostring(on))
		end,
	})
	togglesTab:CreateToggle({ Name = "Toggle C", Callback = print })
	togglesTab:CreateToggle({ Name = "Toggle D", Callback = print })
	togglesTab:CreateToggle({ Name = "A lone toggle stays full width", Callback = print })
	togglesTab:CreateSection("Buttons")
	togglesTab:CreateButton({
		Name = "Flip Toggle A",
		Callback = function()
			c.toggleA:Set(not c.toggleA:Get())
		end,
	})
	togglesTab:CreateButton({
		Name = "Print hello",
		Callback = function()
			print("[Hoodz test] hello from a button")
		end,
	})

	local slidersTab = components:CreateTab("Sliders")
	local readout = slidersTab:CreateLabel("Slider value: 50")
	slidersTab:CreateSection("Values")
	c.sliderA = slidersTab:CreateSlider({
		Name = "Whole numbers",
		Min = 0,
		Max = 100,
		Default = 50,
		Increment = 1,
		Callback = function(v)
			readout:Set("Slider value: " .. v)
		end,
	})
	c.sliderB = slidersTab:CreateSlider({
		Name = "Decimals (0.05 steps)",
		Min = 0,
		Max = 1,
		Default = 0.5,
		Increment = 0.05,
	})
	slidersTab:CreateSlider({ Name = "Big range (step 10)", Min = 0, Max = 500, Default = 100, Increment = 10 })

	-- Category 2: Stress Test
	local stress = UI:CreateCategory("Stress Test")
	local scrollTab = stress:CreateTab("Scrolling")
	for i = 1, 6 do
		scrollTab:CreateSlider({ Name = "Value " .. i, Min = 0, Max = 10, Default = i })
	end
	for i = 1, 6 do
		scrollTab:CreateToggle({ Name = "Option " .. i })
	end

	-- Category 3: Tests (self-test report)
	local tests = UI:CreateCategory("Tests")
	local report = tests:CreateTab("Self-test")
	if summary then
		local passed = 0
		for _, r in ipairs(summary) do
			if r.ok then
				passed += 1
			end
		end
		report:CreateSection(passed .. " / " .. #summary .. " passed")
		for _, r in ipairs(summary) do
			report:CreateLabel((r.ok and "PASS   " or "FAIL   ") .. r.name)
		end
	else
		c.report = report
		c.status = report:CreateLabel("Running self-test...")
	end

	return UI, c
end

----------------------------------------------------------------------
-- Self-test
----------------------------------------------------------------------
local UI, c = build(Hoodz, nil)
check("library exposes new()", type(Hoodz.new) == "function")
check("UI finished loading", UI:WaitUntilLoaded(40))

-- components
c.toggleA:Set(true, true)
check("toggle: Set(true) then Get() == true", c.toggleA:Get() == true)
c.toggleA:Set(false, true)
check("toggle: Set(false) then Get() == false", c.toggleA:Get() == false)
c.sliderA:Set(150)
check("slider: value above Max is clamped to 100", c.sliderA:Get() == 100)
c.sliderA:Set(33.4)
check("slider: Increment 1 rounds 33.4 to 33", c.sliderA:Get() == 33)
c.sliderB:Set(0.37)
check("slider: Increment 0.05 rounds 0.37 to 0.35", c.sliderB:Get() == 0.35)

-- built-in settings
local oldVol, oldMusic, oldXf = UI.Settings.Volume, UI.Settings.Music, UI.Settings.Crossfade
UI:SetVolume(25)
check("settings: SetVolume(25)", UI.Settings.Volume == 25)
UI:SetCrossfade(6)
check("settings: SetCrossfade(6)", UI.Settings.Crossfade == 6)
UI:SetMusic(not oldMusic)
check("settings: SetMusic toggles", UI.Settings.Music == (not oldMusic))
UI:SetMusic(oldMusic)
UI:SetVolume(oldVol)
UI:SetCrossfade(oldXf)
check("settings: values restored", UI.Settings.Music == oldMusic and UI.Settings.Volume == oldVol)
check("built-in Settings tab exists", UI.SettingsTab ~= nil)

-- show / hide
UI:SetVisible(false)
task.wait(0.4)
check("SetVisible(false) hides the UI", UI.Main.Visible == false)
UI:SetVisible(true)
task.wait(0.4)
check("SetVisible(true) shows the UI", UI.Main.Visible == true)

local function countPassed()
	local n = 0
	for _, r in ipairs(results) do
		if r.ok then
			n += 1
		end
	end
	return n
end

if RELOAD_TEST then
	-- reload: loading the library a second time must replace the first UI
	local first = UI
	local lib2 = loadLib()
	task.wait(0.3)
	check("reload: loading the library again destroys the old UI", first.Gui.Parent == nil)
	check("reload: a fresh library table is returned", lib2 ~= nil and lib2 ~= Hoodz)
	-- rebuild with the new library and show the report
	UI = build(lib2, results)
else
	-- single load: write the results into the existing UI
	c.status:Set(countPassed() .. " / " .. #results .. " passed")
	for _, r in ipairs(results) do
		c.report:CreateLabel((r.ok and "PASS   " or "FAIL   ") .. r.name)
	end
end

print(("[Hoodz test] done: %d / %d passed"):format(countPassed(), #results))

Help and hosting

The logo does not show

The logo is downloaded from IMG_3411.jpeg in the repo root. Check the file name, or pass your own link with ImageUrl = "<raw link>". Your executor also needs getcustomasset, writefile and isfile. Without a logo you get a red “H” button instead.

There is no music

Check that substance.mp3 is in the repo root, that Background music is on in the Hoodz settings, and that your volume is above 0. The first run downloads the file, which can take a few seconds on the loading screen.

The UI is too big or too small

The panels scale to the screen automatically. If it still looks wrong, tell me your device and screen size and the scale limits can be adjusted.

How do I put this page online?

Save this file as index.html in the root of your repository, then open the repository’s Settings → Pages and publish the main branch. The page then lives at https://animstation.github.io/HoodzGui/.

Can I change the colors?

The colors live in the Theme table at the top of HoodzLib.lua (Hoodz.Theme after loading). Change them in the library file and every panel follows.
